AI Student Performance Predictor

Machine Learning Project | Python | Google Colab

Project Overview

The AI Student Performance Predictor is an educational machine-learning prototype designed to explore how study habits and academic indicators can be used to estimate student quiz scores.

The project was developed as part of my journey into artificial intelligence and programming.

Project Objectives

* Understand how machine-learning algorithms learn from data.
* Explore relationships between study hours, attendance, previous scores, and quiz performance.
* Train and evaluate a Linear Regression model.
* Develop an interactive interface for entering student information.

Technologies Used

* Python
* Google Colab
* Pandas and NumPy
* Scikit-learn
* Matplotlib
* Gradio

How It Works

1. Generate a synthetic dataset containing 200 fictional student records.
2. Divide the data into 80% training and 20% testing sets.
3. Train a Linear Regression model to predict quiz scores.
4. Evaluate the predictions using Mean Absolute Error (MAE) and R-squared (R²).
5. Compare the model with a simple baseline.
6. Use Gradio to create an interactive prediction interface.

Project Limitations

All student records are artificially generated for educational purposes. The model has not been validated on real student data and should not be used for actual academic decisions.

Future Improvements

* Experiment with real, appropriately licensed and anonymized educational datasets.
* Compare different machine-learning algorithms.
* Improve the interface and visualizations.
* Investigate fairness, privacy, and model reliability.
